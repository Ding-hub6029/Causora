**Validation chain:** `PYTHONPATH=src python -m pytest -q tests` → generated structural JSON Schemas (`jsonschema`) → `node scripts/verify_v41.mjs /path/to/causora` invokes Xiangfeng's **actual** `validateMockData` → build throwaway frontend copy with adapted JSON → manual browser Evidence, Boardroom, Brief and PDF page-4 check. These checks verify compatibility, **not** legal approval, provider quality or production G1.

**Day 1 boundary:** The static LOCAL MOCK demonstrates page-linked evidence, strict schemas, provider connectivity and frontend pass-through; **neither real simulation nor human signoff nor bbox highlighting is required to accept this mock handoff**. No owner has yet signed the team's collective G1 walkthrough.

**Later integration:** Human review before any real `BusinessVariable` promotion; real dataset/backend DTO validation; owner-reviewed approval wording/gating; optional locator tuple loader and page-region highlighting. Jinzhu independently supplies a documented 104-week calculation and oracle: **deterministic mode may report `monteCarloRuns: 0`; stochastic mode reports its actual positive draw count**. Do not infer static/mock status solely from that field. Xiangfeng's original unsigned `API_CONTRACT.md` §1 currently requests a positive production run count; the team should explicitly revise that sentence to distinguish deterministic from Monte Carlo execution without modifying the original v4.1 ZIP here. Day 3–4 agent orchestration, full numeric guardrail and fallback remain outside this Day 1 package.
