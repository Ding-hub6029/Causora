# Recording guide

Use Speech_10_Minutes_Core_Code.pdf as the revised ten-minute recording script. Each page puts a website image or a numbered source excerpt above the matching narration. The instructions and links beneath tell you which GitHub file to open and when to turn the page.

This version replaces the earlier product-heavy narration for the recording. It devotes most of the video to implementation. Eighteen PDF pages are recording segments, not eighteen presentation slides.

The code links pin the production source under Day5/Causora. Member Day5 and Day6 folders are delivery snapshots, so they are not the source to open for this walkthrough. Code panels reproduce source text rather than a GitHub browser screenshot. Website images show historical validated results.

Read only the narration. Keep source tabs ready before recording. Do not read line numbers or full code aloud. Hide API keys and database credentials. Explain reservations and receipts without showing secret values.

The examples use synthetic data. The human choice stays local to the browser. This guide does not claim repeated production reliability, a measured independent Critic recall rate, or universal superiority over other AI products.
