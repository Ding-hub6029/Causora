The PDF condition is “If written notice is not received at least 60 days before renewal.” The frozen mock uses the explicit synthetic inputs `contract.decisionDate = 2026-10-04`, `contract.renewalDate = 2026-11-18`, `contract.daysToRenewal = 45`, `contract.renewalNoticeDays = 60`, and `contract.noticeSent = false` (`causora_day1_mock.json` keys `contract.*`). As stated by the API contract, the renewal is treated as locked only because `45 < 60` **and** the synthetic `noticeSent` input is false; an earlier valid written notice would change the outcome (`API_CONTRACT.md`, lines 31 and 98).
