# Day 4 Integration Test Entry Point

This directory is deliberately included in `../pytest.ini` so future Day 4 integration tests are collected by the default `pytest` command.

The current Day 4 provider, deadline, guardrail, budget, source-evidence, and failure-mode regressions are retained in `../tests/` for compatibility with Wang's latest source layout. New cross-owner Day 4 integration tests may be placed here without changing the default test command.
